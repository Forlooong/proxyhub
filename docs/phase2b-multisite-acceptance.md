# 阶段 2b：多站点与证书依赖验收

日期：2026-10-15（Asia/Shanghai）。版本：`0.4.0a1`。沿用专用 Debian 12 amd64 VPS、sing-box 1.14.3、Mihomo 1.19.32、Nginx 1.30.5 和 Node 24.21.0。本增量遵循重对齐总方案第 10.2 节；完整阶段 2 与首版发行仍未完成。

## 交付

网站、证书绑定和内部监听具有稳定编号，保存在现有版本化配置中。旧网站及共享证书归一化为 `default`；新增资源使用独立 ID，原网站继续使用 `site/`，其他网站使用按 ID 隔离的内容目录。证书绑定身份独立于证书材料和指纹。

CLI 与面板接入创建、选择、启用、停用和删除网站，域名绑定/解绑，逐站内容上传与恢复，以及证书申请、导入、替换、续期、消费者列表和依赖删除保护。保留原命令及默认网站参数行为，详细操作见[面板手册](panel.md)。

网站和证书变更使用受约束的 Web 激活，只重载 Nginx 和订阅发布器，保留代理进程。每个启用的网站及订阅 TLS 消费者均须实际返回所选证书指纹；网站正文也须与候选一致，全部通过才提交。失败恢复上一配置、证书和内容。

## 验收结果

| 检查 | 结果 |
| --- | --- |
| Linux 相关测试 | 网站资源、管理变更、证书、部署/恢复、内容隔离、管理接口、CLI、网关及渲染共 346 项通过，另有 125 项 subtests 通过。首次 345 passed、1 failed；失败为迁移测试未同步新旧内容字段，修正该输入后仅补跑该项，1 passed |
| 自动续期失败隔离 | 新增 5 项针对性 CLI 测试通过：单绑定失败继续后续独立 lineage，存在 pending/BUSY 时停止，部分失败或全部失败退出 1；旧配置续期路径保持兼容 |
| 前端 | TypeScript 检查、Vite 构建通过。真实 Edge 验收站点切换、证书申请与消费者、创建网站、文件选择器上传、显式应用；390px 与 1440px 无横向溢出，控制台 0 errors / 0 warnings |
| 旧配置升级 | 先以默认网站重新绑定当前证书，执行 Web-only 归一化激活；保留原网站内容和 2a 历史，再申请新增域名证书。新版默认 HTTP challenge 已实际完成首次新域名 HTTP-01 验证 |
| 双站点 HTTPS | 原网站与新增网站分别通过公网 HTTPS，使用独立证书绑定和内部监听。每个启用消费者的实际指纹和正文与候选一致，原网站仍经原 REALITY 路径 |
| 生命周期与冲突 | 新站停用、解绑最后域名、重新绑定、启用均通过，网站/监听 ID 和端口保持不变；重复 SNI 拒绝。启用计划准备后占用该端口，应用在切换配置前拒绝；释放后同一有效计划可应用 |
| 依赖保护 | 默认网站停用/删除、解绑原 REALITY SNI、删除默认共享证书及删除被新站引用的证书均拒绝；停用且没有域名的网站仍保留证书依赖 |
| 逐站内容 | 新站两文件 ZIP 预览、上传、模板恢复和自身历史恢复通过；iframe 无权限 sandbox，脚本数为 0。原 2a 历史仍可见，新站内容未混入默认网站历史，公网正文与对应站点内容一致 |
| 证书管理 | 新域名独立 lineage 签发成功，原 lineage 保留；原证书和新证书实际续期检查均为 unchanged，没有强制续期。CLI 导入手工证书并重新绑定新站通过，手工绑定不会因相同材料属于其他 lineage 而被接管续期 |
| 新消费者失败恢复 | 为新站生成 SAN/密钥有效但不受信任的测试证书；候选通过静态检查后，实际消费者 TLS 健康检查失败。旧可信证书恢复、revision 未提交、计划标记 failed、journal 无待恢复项 |
| 真实客户端 | 从个人电脑下载当前订阅，GET/HEAD 元数据一致、未知令牌拒绝、覆盖保留；锁定 Mihomo 导入成功，并通过现有 REALITY 节点完成真实公网代理请求 |
| 配置和服务保留 | 验收期间用户主动修改过配置；随后按该配置建立验收基线。网站和证书测试后，服务器/订阅/覆盖配置与原站正文摘要均与此基线相同；proxy/nginx/publisher 主 PID 全程相同。没有修改原项目命令、SSH 或防火墙 |
| 部署一致性 | 281 个应用、前端、生成器及锁定运行时文件的 SHA-256 与部署包逐项一致，文件属主和不可组/其他用户写入权限通过；五项常驻服务均为 active |
| 独立审查 | 修复并复核 2a 升级时 challenge 激活顺序、单证书失败阻断后续续期的问题；最终只读复核未发现剩余阻断 |

Windows 上部分真实 OpenSSL 和 POSIX 权限检查受宿主沙箱限制，对应检查已在 Linux 上通过，没有放宽路径或权限校验。上述数量仅描述各次检查，不相加推算覆盖率。

新增站点保留默认模板及有效独立证书，便于继续通过面板查看；成功上传的内容作为正常恢复历史保留。手工导入测试产生的额外绑定已解除引用并删除，验收源副本、客户端日志、测试 ZIP、浏览器登录日志及其他任务临时文件按本次范围清理；保留一份升级前应用备份。证书私钥不离开服务器，公开记录不保存服务器身份、真实域名、凭据或订阅链接。

## 后续门槛
