# 管理面板阶段验收

核验日期：2026-10-14。版本：`0.2.0a1`。使用原专用 Debian 12 amd64 测试 VPS，保持原 SSH 端口、密码/root 登录策略和原项目命令。面板仅监听 `127.0.0.1:18765`，通过已有 SSH 密钥隧道访问。

## 交付与范围

React / TypeScript 面板包含总览、服务器、网站证书、代理、订阅、任务和帮助。资源关系图、深浅色、移动导航、键盘命令菜单、变更预览、任务轮询和显式凭据显示连接真实 API。实现及安装见 [面板手册](panel.md)，视觉来源与权衡见 [设计记录](../packages/panel/DESIGN.md)。

本阶段连接已有单网站/单 REALITY/单订阅能力。网站标题编辑、证书导入/受管续期、节点名称/客户端地址、公钥追加、订阅元数据与受控 JSON 覆盖均已实现。完整多网站生命周期、目标切换、HY2、规则流水线和自动计量仍属于后续阶段。

## 验收发现与修复

真实安装首先拒绝了 Windows 归档继承的宽松写权限。打包器现显式归一化文件所有者及 `0644` 权限，不携带私有文件。

首次完整网站激活暴露 `UMask=0077` 会把候选目录的 `mkdir(0711)` 压成 `0700`，代理进程因此无法读取配置，回滚也因上一订阅候选同样受影响而中断。已将修复限制在本次测试生效版本并执行恢复；随后新增明确 chmod 和激活前权限检查，两种激活模式都必须通过。新增 12 项真实 POSIX 回归，最终网站/节点完整重载、公网请求及恢复测试通过。未对全部历史版本批量修改权限。

另外修复了证书异常阻断整个 overview、配置与 revision 快照不一致、SSH 转发策略误判、续期父计划未终结、重复管理器启动污染任务状态，以及前端凭据显示竞争、日期精度和退出失败清屏问题。
