# 阶段 2a：网站内容生命周期验收

日期：2026-10-15（Asia/Shanghai）。版本：`0.3.0a1`。沿用专用 Debian 12 amd64 VPS，以及 sing-box 1.14.3、Mihomo 1.19.32、Nginx 1.30.5 和 Node 24.21.0。此次交付属于总设计“阶段 2：网站与代理管理”的单站点内容增量，完整阶段 2 尚未结束。

## 交付

管理面板与 `proxyhub site content` CLI 支持 ZIP 上传、准备候选、禁脚本隔离预览、显式应用、成功内容版本列表、历史内容恢复与默认模板恢复。复用原部署目录、哈希清单、revision、journal 和回滚流程，没有新增内容数据库或公网管理入口。

压缩 ZIP 限制 180 KiB，实际解压 2 MiB，文件和隐含目录合计最多 200 项；根 `index.html` 必须是非空 UTF-8，最大 256 KiB。预览最多 512 KiB，使用 HTMLParser 白名单和无权限 sandbox iframe。公网静态资源具备对应 MIME 与 CSP；预览不执行 JavaScript，公网网站可执行同源外置 JS，详细边界见[面板手册](panel.md)。
